A persistent Linux machine for your coding agent

Chasm gives each coding agent its own Linux VM on your own machine. Its disk, packages and workspace stay put between sessions. Leave it running for weeks, stop it and pick up later, or delete it when you’re done.

Install Chasm

  • Stays put

    Installed packages, the root disk and /workspace survive stop and start. Nothing to rebuild each session.

  • Its own kernel

    A real VM, not a container. The agent never shares your host’s kernel.

  • On your hardware

    No cloud service or account. Sandboxes and their data stay on your host.

Install

On Debian 13 (x86_64) with KVM (nested virtualization disabled) and Go 1.23 or newer on root’s PATH:

{% highlight bash %} git clone https://github.com/rahulrajaram/chasm.git cd chasm sudo scripts/install-chasm.sh --provision --install-incus sudo scripts/install-chasm.sh --verify {% endhighlight %}

The default storage pool needs 74 GiB free. On a smaller disk, use the compact install. Full requirements →

Run your agent

{% highlight bash %} # Create a VM and open a shell in it, then install and run your agent there chasm create demo chasm start demo chasm shell demo # Back on the host: keep it for later, or throw it away chasm stop demo chasm delete demo {% endhighlight %}
