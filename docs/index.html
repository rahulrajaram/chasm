Long-horizon VMs for long-horizon agents

Fully sandboxed VMs, shared disk pools. Truly long-horizon agentic orchestration on agentic OSes.

Install

{% highlight bash %} git clone https://github.com/rahulrajaram/chasm.git cd chasm sudo scripts/install-chasm.sh --provision --install-incus sudo scripts/install-chasm.sh --verify {% endhighlight %}

Run

{% highlight bash %} # Create a VM and open a shell in it, then install and run your agent there chasm create demo chasm start demo chasm shell demo # Or run one command from the host, with its exit status passed back chasm exec demo -- uname -a # Back on the host: keep it for later, or throw it away chasm stop demo chasm delete demo {% endhighlight %}
