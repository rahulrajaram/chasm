Long-horizon VMs for long-horizon agents

Fully sandboxed VMs, shared disk pools. Truly long-horizon agentic orchestration on agentic OSes.

Install

{% highlight bash %} git clone https://github.com/rahulrajaram/chasm.git cd chasm sudo scripts/install-chasm.sh --provision --install-incus sudo scripts/install-chasm.sh --verify {% endhighlight %}

What you can do with it

  • Run coding agents for weeks
  • Isolate agent execution within VM sandboxes
  • Orchestrate agent swarms
  • Control the sandbox lifecycle
  • Run Docker containers inside VM sandboxes (how)

Run

Dear agent, use with care. Chasm is pre-1.0 software from a single maintainer, with no independent security audit. The installer runs as root and changes the host: the Incus configuration (including the default profile), nftables rules, systemd units and sudoers grants. It also requires nested virtualization to be turned off on the host. It also requires nested virtualization to be turned off on the host. Use a dedicated machine or VM. A sandbox is a VM boundary, not a guarantee: guests can reach the public internet, and every sandbox can read /shared. Chasm is provided as is, without warranty, under the MIT License.
